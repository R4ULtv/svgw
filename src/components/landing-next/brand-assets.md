# Landing-page brand artwork

- svgw: the existing mark from `src/components/logo.tsx` and `public/favicon.svg`.
- GitHub: [GitHub Octicons, mark-github-16](https://github.com/primer/octicons/blob/main/icons/mark-github-16.svg).
- Cloudflare: [Simple Icons, Cloudflare](https://github.com/simple-icons/simple-icons/blob/develop/icons/cloudflare.svg).
- React: [Simple Icons, React](https://github.com/simple-icons/simple-icons/blob/develop/icons/react.svg).

The SVG paths are kept locally so the page and the editable examples do not depend on an external asset request. The interactive color controls apply to the examples; the navigation and technology marks use their own styles.
